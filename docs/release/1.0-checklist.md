Written 2026-10-07 (step 8, Task 27; [the plan](../plans/2026-10-06-step-8-operations.md), "Task
27"). One row per thing 1.0 needs: the plan's 1.0 gate, every step's definition of done, every
carry-over file, every row of the §19 register of assumptions that is still a check, and every
row of the five device checklists. Each row has one state:

- **done**, with its evidence (a commit, a test, a doc);
- **deferred**, with the reason (1.x, the cloud phase, or a feature that ships off);
- **maintainer**, with what only you can do: the command, the setting or the row to run.

A "maintainer" row that is a decision says which way the build leaned. Nothing here is ticked on
a claim: where a result is inferred, the row says so.
